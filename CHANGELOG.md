# Change Log

All notable changes to the **Image Viewer SE (Spawn Era)** extension will be documented in this file.

## [1.1.4] - 2026-08-29

### Changed
- **Documentation**: Change preview image.

## [1.1.3] - 2026-08-29

### Added
- **Portrait Aspect Ratios**: Added support for `3:4` and `9:16` Portrait grid tiles in settings and layout calculations.
- **Batch File Operations**: Introduced tools for moving files, deleting, renaming, grouping selected files, and creating single or bulk folders.
- **Custom Display Modes**: Choose between Accordions + Filenames, Accordions Only, Flat List with Filenames, or Flat Dense Grid.
- **Folder Scoping**: Dedicated editor tab titles and folder-scoped scanning when opening from File Explorer context menu.
- **Enhanced Lightbox**: Interactive zoom, pan, rotate, flip, and thumbnail minimap preview engine.

### Initial Release
- **Image Viewer SE (Spawn Era)** initial release on Open VSX, modified from the original open-source [vscode-image-viewer](https://github.com/ZhangJian1713/vscode-image-viewer) by ZhangJian1713.
